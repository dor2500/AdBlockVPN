# Release Notes

## v1.0.1 (Current Unreleased)
- **Whitelisting**: Added essential domains for WhatsApp (media/images), TikTok, YouTube, and Google Gemini to prevent them from breaking under aggressive filtering.
- **Localization**: Added full Hebrew language support (auto-detects based on device settings).
- **Redesign**: Completely overhauled the UI from a neon-cyberpunk style to a clean, professional, premium "Slate & Blue" aesthetic (similar to top-tier VPN apps).
- **Auto-Updates**: Implemented an automatic update checker that fetches the latest release directly from GitHub Releases and prompts the user to install the APK.

### עברית
- **רשימה לבנה (Whitelisting):** הוספת דומיינים חיוניים עבור WhatsApp (שליחת מדיה), TikTok, YouTube, ו-Google Gemini כדי למנוע חסימה שלהם ולשמור על פעילות תקינה.
- **שפות (Localization):** הוספת תמיכה מלאה בשפה העברית (המערכת מזהה אוטומטית לפי שפת המכשיר).
- **עיצוב מחדש (Redesign):** שדרוג הממשק לחלוטין מעיצוב מצועצע לעיצוב פרימיום בוגר, מקצועי ונקי (בסגנון Slate & Blue, בדומה לאפליקציות VPN מובילות).
- **עדכונים אוטומטיים:** שילוב מנגנון עדכונים אוטומטי שמושך את הגרסה העדכנית ביותר ישירות מעמוד ה-Releases ב-GitHub ומקפיץ למשתמש התראה להתקנת העדכון.
